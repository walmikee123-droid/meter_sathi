Frequently Asked Questions

Answers to common questions about Meter-Sathi and how to use the app.

Below are quick answers to the questions we hear most often. If you don't find what you're looking for, visit the Contact page to get in touch.

How does ride tracking work?

Ride tracking uses your device's geolocation (with your permission) to record start and end points, calculate distance, and estimate the official fare based on the selected vehicle tariff.

What if my browser blocks location access?

Geolocation requires a secure context (HTTPS) or http://localhost. If blocked, enable location in your browser's site settings or test locally. The app will show a helpful message if location is unavailable.

Which tariffs are used for calculations?

Meter-Sathi applies official tariffs for the selected vehicle type and city. Choose Auto Rickshaw or Taxi at the start; taxi and auto pages use different base fares and per-kilometer rates.

Why does the official fare show a base amount immediately?

The official fare displays the minimum base fare (for example, ₹26 for autos) so you always see the minimum payable amount even before any distance is recorded.

Can I use the app without granting location permission?

Core features require location permission for accurate tracking. If you prefer not to grant permission, you can still enter meter values manually on the ride page to compare fares.

How accurate is the distance calculation?

Distance is calculated using the Haversine formula between successive GPS coordinates. Accuracy depends on device GPS/Wi‑Fi positioning and signal quality; enable high accuracy in device settings for best results.

Where can I report repeated overcharging?

Use the Contact page to report incidents. Provide ride details, date/time, and any supporting information so we can guide you on next steps and escalate if necessary.
